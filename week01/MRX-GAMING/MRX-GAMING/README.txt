MRX GAMING - Week 01 Web Programming Assignment

HOW TO RUN
1. Extract MRX-GAMING.zip.
2. Open the MRX-GAMING folder in Visual Studio Code.
3. Open index.html in your browser (or use Live Server if installed).
4. Use the navigation links to move between Home and Games.

PROJECT CONTENTS
- index.html: Home page
- games.html: Games page
- css/style.css: All website styling and responsive media queries
- images/: Local SVG game illustrations

ASSIGNMENT NOTES
- Built with HTML and CSS only.
- No JavaScript.
- No Bootstrap or website templates.
- Responsive layouts use CSS Grid, Flexbox and media queries.
- Images are local files and scale to fit their cards.
